A toast confirms an action or reports a background event without
interrupting: “Page published”, “Draft saved”, “Upload failed”. It appears
in the bottom-right corner and goes away on its own.

For a problem people must fix before they can go on, use an
[InlineAlert](/feedback/inline-alert) next to its cause; for a decision,
an [AlertDialog](/overlays/alert-dialog).

## Setup

Sprinkles keeps no global state, so the app creates the toast store itself,
once, where it starts, and renders one `<Toaster>` for it. Share the store
with the rest of the app through a context (or a module, if your app allows
module state); anything that can reach it can send toasts.

```tsx
import { type ToastStore, Toaster, createToaster } from '@webf/sprinkles';
import { createContext, useContext } from 'solid-js';

const ToastContext = createContext<ToastStore>();
export const useToaster = () => useContext(ToastContext)!;

export function App() {
  const toaster = createToaster();
  return (
    <ToastContext.Provider value={toaster}>
      <Toaster toaster={toaster} />
      <Editor />
    </ToastContext.Provider>
  );
}

// In any component below App:
useToaster().success({ title: 'Page published' });
```

`createToaster` takes Ark UI's options, with these defaults: `placement:
'bottom-end'`, `overlap: false` (toasts stack instead of piling up), `gap:
12` and `max: 5`. The examples on this page share one store, `toaster`.

## Types

The type picks the colour (a semantic role) and the icon.

| Call                                  | Type      | Role          | Lasts |
| ------------------------------------- | --------- | ------------- | ----- |
| `toaster.create({ type: 'neutral' })` | `neutral` | `neutral`     | 5 s   |
| `toaster.info()`                      | `info`    | `informative` | 5 s   |
| `toaster.success()`                   | `success` | `positive`    | 2 s   |
| `toaster.warning()`                   | `warning` | `notice`      | 5 s   |
| `toaster.error()`                     | `error`   | `negative`    | 5 s   |

`toaster.create()` without a type makes an `info` toast, so pass
`type: 'neutral'` for a plain one. Pass `duration` (ms) to change how long
one stays, or `Infinity` to keep it
until it's dismissed. A toast also stays while the pointer is over the stack
or focus is inside it.

## With an action

`action: { label, onClick }` adds one button; choosing it also dismisses the
toast. Give the toast a longer `duration` so the action can be read and
reached, and make it something people can also do elsewhere, since the
toast may be gone before they get to it.

## States

- **Entering:** slides in from the bottom edge (200 ms), pushing older
  toasts up.
- **Paused:** the countdown stops while the pointer is over the stack, focus
  is inside it, or the browser tab is hidden.
- **Leaving:** slides out and fades (200 ms) when its time is up, when the
  close button or action is pressed, or on Escape.
- **Reduced motion:** toasts appear and disappear without moving.

## Accessibility

- The stack is a `region` labelled “Notifications” with `aria-live="polite"`,
  so screen readers read new toasts without interrupting.
- Alt+T moves focus to the stack; Tab reaches each toast's action and close
  button. Escape dismisses the focused toast.
- The close button is labelled “Dismiss notification”.
- White text on each role's bold fill passes 4.5:1 contrast in the default
  theme.

## Props

`<Toaster>`:

| Prop      | Type                                         | Default           |
| --------- | -------------------------------------------- | ----------------- |
| `toaster` | `ToastStore`, from `createToaster`; required |                   |
| `label`   | `string`; names the region                   | `'Notifications'` |
| `class`   | `string`; added to the stack                 |                   |

Each toast (`toaster.create(options)` and friends):

| Option        | Type                                                                    | Default   |
| ------------- | ----------------------------------------------------------------------- | --------- |
| `title`       | `JSX.Element`                                                           |           |
| `description` | `JSX.Element`                                                           |           |
| `type`        | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'error' \| 'loading'` | `'info'`  |
| `action`      | `{ label: string; onClick: () => void }`                                |           |
| `duration`    | `number` (ms)                                                           | by type   |
| `closable`    | `boolean`; shows the close button                                       | `true`    |
| `id`          | `string`; to update or dismiss it later                                 | generated |
