A stat card shows one number and its label: “98%, placement rate”. Use them in a row of three to five.

## Sizes

S and M are fixed-width tiles. L is square on phones and a fixed height from `md` up, with large type, for a row of headline figures.

  <SizesOutput />
</ExampleBlock>

## Fill style

`outline` (default), `subtle` and `bold`, as on every marketing card.

<ExampleBlock code={fillStylesCode}>
  <FillStylesOutput />

## Accessibility

- The figure and label are paragraphs, not headings: a page's outline shouldn't be a list of numbers.
- Write the label so the pair reads as a sentence (“98% placement rate”).

## Props

| Prop                                | Type                                           | Default     |
| ----------------------------------- | ---------------------------------------------- | ----------- |
| `value`                             | `string`                                       |             |
| `label`                             | `string`                                       |             |
| `icon`                              | a lucide-solid icon                            |             |
| `variant`                           | a role, `'highlight'`, or a categorical colour | `'accent'`  |
| `fillStyle`                         | `'outline' \| 'subtle' \| 'bold'`              | `'outline'` |
| `size`                              | `'s' \| 'm' \| 'l'`                            | `'m'`       |
| `iconBackground`                    | `boolean`                                      | `true`      |
| `lift`                              | `boolean`                                      | `false`     |
| `iconClass, valueClass, labelClass` | `string`                                       |             |
