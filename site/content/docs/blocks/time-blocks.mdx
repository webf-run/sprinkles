## Writing good entries

- Name what the time is for: “Pick-up time” or “Appointment time”, not just “Time”.
- Put the rules in `description`, in plain words: “Open 9:00 AM to 5:00 PM.” People see them before they choose.
- Make `errorText` say what to do next: “Choose a time between 9:00 AM and 5:00 PM.”
- Use the 12-hour clock for customers and the 24-hour clock for rotas and timetables. Use one style across a page.
- Show only the units people need. Use `granularity='hour'` for whole hours and add seconds only for alarms and timers.
- Use `minuteStep` to match your slots, such as 15 for appointments, so the arrow keys only land on times you accept.

## Accessibility

- Give every field a visible `label`. Use `aria-label` only where a label truly can't fit, such as a field inside a table row.
- Each segment (hour, minute, AM/PM) is a spin button with a localized name and its current value, so screen readers announce it and the arrow keys change it.
- `required`, `disabled` and `readOnly` are exposed to assistive technology.
- Don't rely on colour alone to show an invalid time. Always add `errorText` that explains the problem.
- When two fields depend on each other, such as a start and an end time, say the rule in `description` so it is read with the field.

## Props

These blocks are built from [TimeField](/fields/time-field), so they take its props.

| Prop                                          | Type                              | Default            |
| --------------------------------------------- | --------------------------------- | ------------------ |
| `value`                                       | `string \| null`                  | —                  |
| `defaultValue`                                | `string \| null`                  | —                  |
| `onValueChange`                               | `(value: string \| null) => void` | —                  |
| `granularity`                                 | `'hour' \| 'minute' \| 'second'`  | `'minute'`         |
| `hourCycle`                                   | `12 \| 24`                        | Locale             |
| `locale`                                      | `string` (BCP 47)                 | Ark locale context |
| `min`, `max`                                  | `string` (`HH:mm` or `HH:mm:ss`)  | —                  |
| `minuteStep`                                  | `number` (positive integer)       | `1`                |
| `placeholderValue`                            | `string` (`HH:mm`)                | `'00:00'`          |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`       | `'m'`              |
| `tone`                                        | `Tone`                            | `'accent'`         |
| `fillStyle`                                   | `'outline' \| 'subtle'`           | `'outline'`        |
| `quiet`, `icon`                               | `boolean`                         | `false`            |
| `name`                                        | `string`                          | —                  |
| `label`, `description`, `errorText`           | `JSX.Element`                     | —                  |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                         | `false`            |
| `id`, `aria-label`, `class`                   | `string`                          | —                  |
