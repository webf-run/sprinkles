A combobox is a text input that filters a list as people type: an author, a
tag, a parent page. Use it when the list is long enough that typing a few
letters beats scrolling. For a handful of options, use a
[Select](/fields/select/).

## Filtering and value

Options are `{ label, value, disabled? }`, as in Select. Typing keeps the
options whose label contains the text, ignoring case and accents, so "jose"
finds "José Álvarez". The value is the option's `value`, or `null`; with
`name`, that value (not the label) is submitted with a form.

To load options from a server, listen to `onInputValueChange` and pass the
results as `items`.

When nothing matches, the list says so. `emptyText` replaces the default "No
results" with something more helpful, like where to get a missing option.

## Sizes

S, M, L and XL are 24, 32, 40 and 48 px tall, like every other control; the
options follow the input's size. M is the default.

## States

Hover darkens the outline; keyboard focus draws the focus ring; while the list
is open, the highlighted option is tinted. Invalid turns the outline negative
and shows `errorText`. Disabled is greyed out and skipped by the Tab key.
Read-only shows the value on a muted surface and doesn't open.

## Accessibility

- Built on Ark UI's combobox: the input has `role="combobox"` with
  `aria-expanded` and `aria-activedescendant`, and the list `role="listbox"`.
- Keyboard: typing or Down opens the list; Up and Down move the highlight;
  Enter picks; Escape closes, then clears what was typed.
- Focus stays in the input while the highlight moves, so people can keep
  typing.
- The chevron opens the list for pointer users and is skipped by the Tab key.

## Props

| Prop                                          | Type                                                     | Default        |
| --------------------------------------------- | -------------------------------------------------------- | -------------- |
| `items`                                       | `{ label: string; value: string; disabled?: boolean }[]` |                |
| `value`                                       | `string \| null`                                         |                |
| `defaultValue`                                | `string \| null`                                         |                |
| `onValueChange`                               | `(value: string \| null) => void`                        |                |
| `onInputValueChange`                          | `(text: string) => void`                                 |                |
| `placeholder`                                 | `string`                                                 |                |
| `emptyText`                                   | `JSX.Element`                                            | `'No results'` |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`                              | `'m'`          |
| `name`                                        | `string`; submits the selected value                     |                |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field/)               |                |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                                | `false`        |
| `id`                                          | `string`; the input's id                                 |                |
| `aria-label`                                  | `string`; required without a visible label               |                |
