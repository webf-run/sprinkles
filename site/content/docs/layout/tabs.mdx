Tabs switch between views of one thing: a page's Content, SEO and History.
Only one panel shows at a time. To move between different pages of the
app, use the [AppShell](/layout/app-shell)'s sidebar; to step through a
process, use a stepper or separate pages.

## Vertical

`orientation='vertical'` stacks the tabs beside their panel, for settings
with several sections. The line moves to the tab's left edge, and the up and
down arrow keys move between tabs.

## Sizes

S, M and L tabs are 32, 40 and 48 px tall. M is the default; use S in dense
panels and L for a page's main tabs.

## States

Selected, default, hover (a faint line appears), keyboard focus and
disabled. Selected text is darker and doesn't change weight, so tabs don't
shift as the selection moves.

## Accessibility

- Ark UI gives the list `role="tablist"`, each tab `role="tab"` with
  `aria-selected` and `aria-controls`, and each panel `role="tabpanel"`.
- Tab moves into the tab list (to the selected tab) and then into the panel.
  Left and Right arrows (Up and Down when vertical) move between tabs; Home
  and End jump to the first and last. Disabled tabs are skipped.
- By default a tab is selected as the arrow keys reach it. With
  `activationMode='manual'`, it waits for Enter or Space, for panels that are
  slow to render.
- Name the tab list with `aria-label` when no heading above it does.

## Props

### Tabs

| Prop             | Type                                             | Default        |
| ---------------- | ------------------------------------------------ | -------------- |
| `items`          | `{ value, label, icon?, disabled?, content? }[]` |                |
| `value`          | `string`; controlled selection                   |                |
| `defaultValue`   | `string`; initial selection                      |                |
| `onValueChange`  | `(value: string) => void`                        |                |
| `size`           | `'s' \| 'm' \| 'l'`                              | `'m'`          |
| `orientation`    | `'horizontal' \| 'vertical'`                     | `'horizontal'` |
| `activationMode` | `'automatic' \| 'manual'`                        | `'automatic'`  |
| `aria-label`     | `string`; names the tab list (with `items`)      |                |

### TabList, Tab, TabPanel

| Part       | Props                                                       |
| ---------- | ----------------------------------------------------------- |
| `TabList`  | `aria-label`, `class`                                       |
| `Tab`      | `value` (required), `icon`, `disabled`, `class`, `children` |
| `TabPanel` | `value` (required), `class`, `children`                     |
