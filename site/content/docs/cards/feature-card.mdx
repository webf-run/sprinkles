## Props

| Prop       | Type                                                                                                      | Default     | Description                    |
| ---------- | --------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------ |
| `title`    | `string`                                                                                                  | —           | Feature heading.               |
| `subtitle` | `string`                                                                                                  | —           | Supporting feature text.       |
| `icon`     | `AstroComponent`                                                                                          | —           | Lucide icon component.         |
| `variant`  | `'default' \| 'muted' \| 'accent' \| 'inverse' \| 'purple' \| 'orange' \| 'green' \| 'blue' \| 'neutral'` | `'default'` | Token-based color treatment.   |
| `size`     | `'sm' \| 'md' \| 'lg'`                                                                                    | `'md'`      | Card spacing scale.            |
| `effect`   | `'none' \| 'lift' \| 'glow'`                                                                              | `'none'`    | Hover effect.                  |
| `class`    | `string`                                                                                                  | —           | Additional Tailwind utilities. |
