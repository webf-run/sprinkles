A feature card names one thing a place or product offers, with an icon and a short supporting line: “Research labs, 28 centres”. Use them in a list or grid of three to six. For a figure, use [Stat Card](/cards/stat-card/); for a list of points, [Benefit Card](/cards/benefit-card/).

## Fill style

The marketing cards share one vocabulary. `outline` (default) is a white card with a quiet border, and the tone shows in the icon chip only. `subtle` tints the card. `bold` fills it, for one card that must stand out.

## Variants

`variant` picks the tone: a semantic role when the colour means something, a categorical colour when it only tells items apart. The default is `accent`.

## Accessibility

- The title is an `<h4>`; place the cards under an `<h3>` (or pass the cards inside a list whose heading fits).
- The icon is decorative and hidden from screen readers; the title says what it is.
- `lift` animates only with `prefers-reduced-motion: no-preference`. Use it only when the card is inside a link.

## Props

| Prop                                   | Type                                           | Default     |
| -------------------------------------- | ---------------------------------------------- | ----------- |
| `title`                                | `string`                                       |             |
| `subtitle`                             | `string`                                       |             |
| `icon`                                 | a lucide-solid icon                            |             |
| `variant`                              | a role, `'highlight'`, or a categorical colour | `'accent'`  |
| `fillStyle`                            | `'outline' \| 'subtle' \| 'bold'`              | `'outline'` |
| `size`                                 | `'s' \| 'm' \| 'l'`                            | `'m'`       |
| `lift`                                 | `boolean`                                      | `false`     |
| `titleClass, subtitleClass, iconClass` | `string`                                       |             |
