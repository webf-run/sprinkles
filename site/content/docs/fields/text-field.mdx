A text field takes one line of text: a title, a slug, an email address. For
more than a line, use a [TextArea](/fields/text-area/); for numbers, a
[NumberInput](/fields/number-input/); for a value from a list, a
[Select](/fields/select/) or a [Combobox](/fields/combobox/).

## Types

`type` picks the keyboard on phones and the browser's autofill and checks:
`text` (default), `email`, `url`, `tel`, `search` or `password`. Add
`autocomplete` so browsers can fill in known values.

## Icon

`icon` puts a lucide-solid icon at the start of the input. Use it when the
icon says something the label doesn't, as a search glass does.

## Sizes

S, M, L and XL are 24, 32, 40 and 48 px tall, the same scale as buttons, so a
field and a button side by side line up. M is the default.

## States

Hover darkens the outline; keyboard focus draws the focus ring. Invalid turns
the outline negative and shows `errorText`. Disabled is greyed out and skipped
by the Tab key. Read-only sits on a muted surface; it can be focused, selected
and copied.

## Accessibility

- A native `<input>`, so typing, selection, autofill and spell check work as
  people expect.
- The label names the input, and the description or error describes it; see
  [Field](/fields/field/).
- The icon is decorative (`aria-hidden`). An input without a visible label,
  such as a search box, needs `aria-label`.
- The outline is `border-strong`, which reaches 3:1 against the page.

## Props

| Prop                                          | Type                                                            | Default  |
| --------------------------------------------- | --------------------------------------------------------------- | -------- |
| `value`                                       | `string`                                                        |          |
| `defaultValue`                                | `string`                                                        |          |
| `onValueChange`                               | `(value: string) => void`                                       |          |
| `type`                                        | `'text' \| 'email' \| 'url' \| 'tel' \| 'search' \| 'password'` | `'text'` |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`                                     | `'m'`    |
| `icon`                                        | a lucide-solid icon, at the start                               |          |
| `placeholder`                                 | `string`                                                        |          |
| `name`                                        | `string`                                                        |          |
| `autocomplete`                                | `string`                                                        |          |
| `maxLength`                                   | `number`                                                        |          |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field/)                      |          |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                                       | `false`  |
| `id`                                          | `string`; the input's id                                        |          |
| `aria-label`                                  | `string`; required without a visible label                      |          |
