```tsx
import { BentoGrid } from '@webf/sprinkles';
```

A bento grid turns a handful of photos into a mosaic where one photo leads and
the rest support it. Give it two to six items and it picks the arrangement,
keeps one gap between every tile, crops each photo to fill its tile, and
reflows to two columns when it is narrow.

```tsx
<BentoGrid
  items={[
    { src: '/campus.jpg', alt: 'Ivy-covered campus buildings' },
    { src: '/library.jpg', alt: 'Students reading in the library' },
    { src: '/lab.jpg', alt: 'A laptop screen full of code' },
  ]}
/>
```

Only `src` and `alt` are required. Everything else is optional.

## Mixed layout

Photos and cards together. An item with no `src` is a **card**: a solid
(`bold`) or tinted (`subtle`) tile with a badge, an icon, a big figure, text
and a button. Cards look like the other marketing cards (FeatureCard,
StatCard) with the same `variant` and `fillStyle`. Give a card `media` and a
photo sits inside it.

## Variant

Leave `variant` out for the basic look: white badges and check marks that suit
any photo. Set it (`'positive'`, `'informative'`, `'highlight'`, `'indigo'`…)
and every photo badge and check mark shares that colour, and cards without a
`variant` of their own take it. Buttons on photos stay white; give an action
a `variant` for a coloured one.

## Layouts by number of items

| Items | Arrangement (mosaic)                                          |
| ----- | ------------------------------------------------------------- |
| 2     | Two equal halves                                              |
| 3     | One large (half the grid), two wide                           |
| 4     | One large, one wide, two small                                |
| 5     | One large, one tall, two small, one panoramic banner          |
| 6     | One large, one wide, one tall, three small (one of them wide) |

The first item is always the largest, so put your best photo first.

## Responsive behaviour

The layout follows the grid’s own width, not the window’s, so a grid in a
narrow column gets the two-column layout.

- **42rem (672 px) wide and up:** a four-column mosaic with a fixed height,
  so tiles line up exactly. It is a little taller from 56rem (896 px).
- **Narrower:** two columns. The large and wide tiles span the full width at
  4:3, and the rest are squares, so nothing gets squeezed.
- Small tiles never show their description and check points, and neither do
  tiles that are square in the two-column layout. Screen readers still read
  them. The button always shows, at the smaller size on those tiles.
- A card’s `media` photo shows only where the card has room for it.

## Interaction

- Everything on a tile shows at once; nothing waits for a hover.
- Pass `favorites` to add a heart to every photo. It is a toggle button with
  `aria-pressed`: listen with `onFavoriteChange`, and set `defaultSaved` on
  photos the visitor saved before.

## Photo credits

Give a photo a `credit` and the grid lists it in one quiet line below, which
satisfies licences such as CC BY. Pass `hideCredits` if you credit photos
elsewhere.

## Theming

- Photo tiles use static white and black, like a control’s `staticColor`: a
  dark scrim under the text, white text, and white badges, check marks and
  buttons unless the grid has a `variant`. They look the same in a dark page,
  like the photo does.
- Cards use the same surfaces as the other marketing cards, so they follow the
  page’s colour scheme and a site’s token overrides.
- Titles use the heading font (`--font-heading`); radii, spacing and the focus
  ring come from the theme.

## Accessibility

- `alt` is required on every photo. Describe the photo; the title and
  description are read as the tile’s caption.
- Text over a photo sits on a scrim at least 56% black, so white text keeps a
  contrast of 4.5:1 even on a white photo. Badges are solid, not see-through.
- A description or check points hidden for lack of room stay in the page for
  screen readers.
- The heart is a 40 px button named “Save” and the photo’s title, with
  `aria-pressed` for its state.
- Pass `label` to name the group, and set `headingLevel` so tile titles fit
  the page outline.

## Props

### BentoGrid

| Prop               | Type                                                    | Default   |
| ------------------ | ------------------------------------------------------- | --------- |
| `items`            | `BentoItem[]` (2–6 photos or cards; extras are ignored) |           |
| `variant`          | a role, `'highlight'`, or a categorical colour          | white     |
| `leadSide`         | `'start' \| 'end'`                                      | `'start'` |
| `favorites`        | `boolean`                                               | `false`   |
| `onFavoriteChange` | `(image, saved) => void`                                |           |
| `headingLevel`     | `2 \| 3 \| 4`                                           | `3`       |
| `label`            | `string`                                                |           |
| `hideCredits`      | `boolean`                                               | `false`   |
| `class`            | `string`                                                |           |

### BentoImage

| Prop           | Type                                                 | Default                     |
| -------------- | ---------------------------------------------------- | --------------------------- |
| `src`          | `string`                                             |                             |
| `alt`          | `string`                                             |                             |
| `title`        | `string`                                             |                             |
| `description`  | `string`                                             |                             |
| `badge`        | `string`                                             |                             |
| `badgeVariant` | a role, `'highlight'`, or a categorical colour       | the grid’s `variant`, white |
| `checklist`    | `string[]`                                           |                             |
| `action`       | `{ label, href, variant? }`                          | white button                |
| `position`     | `'center' \| 'top' \| 'bottom' \| 'left' \| 'right'` | `'center'`                  |
| `defaultSaved` | `boolean`, the heart’s starting state                | `false`                     |
| `credit`       | `{ text, href? }`                                    |                             |
