A link takes people somewhere else. It is text, underlined so it reads as a
link without relying on colour. For a call to action that should look like a
button, use [`<Button href>`](/actions/button/#as-a-link).

## Variants

`accent` (default) stands out from the text around it. `secondary` takes the
text's own colour, for links in dense text where colour would be noise.

## Quiet

`quiet` hides the underline until hover. Use it only where the context
already says "these are links", such as a navigation list or a footer.

## Static colour

Over photos or a coloured band, `staticColor='white'` or `'black'` ignores the
theme.

## Accessibility

- Renders a native `<a>`; every attribute (`href`, `target`, `rel`, …) passes
  through.
- Underlined by default, so the link is visible without colour (WCAG 1.4.1).
- Keyboard focus shows the focus ring.
- With `target='_blank'`, say so in the label or add `rel='noopener'`.

## Props

| Prop          | Type                      | Default    |
| ------------- | ------------------------- | ---------- |
| `variant`     | `'accent' \| 'secondary'` | `'accent'` |
| `quiet`       | `boolean`                 | `false`    |
| `staticColor` | `'white' \| 'black'`      |            |
| …             | any `<a>` attribute       |            |
