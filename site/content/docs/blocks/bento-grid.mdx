A bento grid turns a handful of photos into a mosaic where one photo leads and the rest support it. Give it two to six images and it picks the arrangement, keeps one gap between every tile, crops each photo to fill its tile, and reflows for tablets and phones.

```tsx
<BentoGrid
  images={[
    { src: '/campus.jpg', alt: 'Campus' },
    { src: '/library.jpg', alt: 'Library' },
    { src: '/students.jpg', alt: 'Students' },
  ]}
/>
```

Only `src` and `alt` are required. Everything else is optional and appears over the photo.

## Three images

The first photo takes half the grid; the other two share the other half. This one shows every kind of overlay: a badge, a title and description, check points, and a button. Each tile also has a heart that visitors can toggle (`favorites`).

## Mixed layout

Photos, coloured sections and content together. A tile with no `src` is a **card**: a solid or tinted block with a badge, icon, big figure, text and button. Give a card `media` and a photo sits inside it. Each card can take its own `tone`.

## Tone

Leave `tone` out for the basic look: white badges and buttons that suit any photo. Set it (`'positive'`, `'informative'`, `'highlight'`, `'indigo'`…) and every badge, check mark and button in the grid shares that colour.

## Layouts by number of images

| Images | Arrangement (tablet and desktop)                                          |
| ------ | ------------------------------------------------------------------------- |
| 2      | Two equal halves                                                          |
| 3      | One large (half the grid), two wide                                       |
| 4      | One large, one wide, two small                                            |
| 5      | One large, one tall, two small, one panoramic banner                      |
| 6      | One large, one wide, one tall, three small (one of them wide)             |

The first image is always the largest, so put your best photo first.

## Responsive behaviour

- **Desktop and tablet (`md` and up):** a four-column mosaic with a fixed height, so tiles line up exactly. It is a little taller from `lg`.
- **Phone:** two columns. The large and wide photos span the full width at 4:3, and the rest are squares, so nothing gets squeezed.
- On a phone, small tiles show their title and badge; the description, check points and button only appear on tiles with room for them.

## Interaction

- Photos zoom slightly on hover and keyboard focus, and the tile lifts with a soft shadow. Nothing moves for people who prefer reduced motion.
- With a mouse, the description, check points and button slide up on hover or focus. On touch screens they are always visible, since there is no hover.
- Pass `favorites` to add a heart to every tile. It is a real toggle button with `aria-pressed`; listen with `onFavoriteChange`.

## Photo credits

Give a photo a `credit` and the grid lists it in one quiet line below, which satisfies licences such as CC BY. Pass `hideCredits` if you credit photos elsewhere.

## Theming

The grid uses semantic tokens only: surfaces and foregrounds from the inverse set, `positive` for check marks, `radius`, `shadow-elevated` and the shared motion curve. A site that overrides those tokens restyles every grid with no extra CSS.

## Accessibility

- `alt` is required on every image. Describe the photo; the title and description are read as the tile's caption.
- Text over photos sits on a dark gradient for contrast. Keep titles short.
- The details stay in the page when they are visually hidden, so screen reader users always get them, and keyboard focus reveals them.
- Pass `label` to name the group, and set `headingLevel` so tile titles fit the page outline.

## Props

### BentoGrid

| Prop               | Type                                     | Default   |
| ------------------ | ---------------------------------------- | --------- |
| `images`           | `BentoImage[]` (2–6; extras are ignored) |           |
| `tone`             | a role, `'highlight'`, or a categorical colour |       |
| `layout`           | `'start' \| 'end'`                       | `'start'` |
| `favorites`        | `boolean`                                | `false`   |
| `onFavoriteChange` | `(image, saved) => void`                 |           |
| `headingLevel`     | `2 \| 3 \| 4`                            | `3`       |
| `label`            | `string`                                 |           |
| `hideCredits`      | `boolean`                                | `false`   |
| `class`            | `string`                                 |           |
