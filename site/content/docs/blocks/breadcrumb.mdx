A slash-separated trail of the pages above this one. The last item is the current page and isn't a link.

## Accessibility

- Renders `<nav aria-label='Breadcrumb'>` with an ordered list; the current page has `aria-current='page'`.
- The slashes are hidden from screen readers.

## Props

| Prop    | Type                                 | Default |
| ------- | ------------------------------------ | ------- |
| `items` | `{ label: string; href?: string }[]` |         |
