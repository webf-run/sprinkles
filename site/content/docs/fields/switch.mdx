A switch turns a setting on or off, and the change takes effect at once:
maintenance mode, comments, an announcement banner. For a choice that is saved
with a form, or a statement people agree to, use a
[Checkbox](/fields/checkbox/).

An "on" track is filled with the neutral colour. `emphasized` fills it with the
accent colour, for the few switches that should stand out.

## Sizes

The track is 24, 32, 40 or 48 px wide for S, M, L and XL, and the row is as
tall as any control of the same size, so the whole row (label included) is the
target. M is the default.

</ExampleBlock>

## States

Hover and press darken the track; keyboard focus draws the focus ring around
it. The thumb slides where motion is allowed. Disabled greys out the track and
the label. Read-only keeps the value legible, in a muted colour, and ignores
presses.

</ExampleBlock>

## Accessibility

- Built on Ark UI's switch: a visually hidden native checkbox with
  `role="switch"` takes focus, so Space flips it and screen readers announce
  "on" or "off".
- The label is part of the target, so the row is at least 24 × 24 px at every
  size (WCAG 2.2 target size).
- On and off differ in fill and in the thumb's position, not only in colour.
- A switch without a visible label must get an `aria-label`.

## Props

| Prop                                          | Type                                       | Default |
| --------------------------------------------- | ------------------------------------------ | ------- |
| `checked`                                     | `boolean`                                  |         |
| `defaultChecked`                              | `boolean`                                  |         |
| `onCheckedChange`                             | `(checked: boolean) => void`               |         |
| `emphasized`                                  | `boolean`; accent fill when on             | `false` |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`                | `'m'`   |
| `name`                                        | `string`                                   |         |
| `value`                                       | `string`; submitted while on               | `'on'`  |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field/) |         |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                  | `false` |
| `id`                                          | `string`; the hidden input's id            |         |
| `aria-label`                                  | `string`; required without a visible label |         |
