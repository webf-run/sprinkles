An icon button starts an action with an icon alone: edit, delete, close,
open the menu. Use it where space is tight and the icon is one people
already know, such as row actions in a table or a toolbar. When the icon
needs explaining, use a [Button](/actions/button) with a label. For an
on/off setting, use a [Toggle](/actions/toggle).

It is a Button underneath, so variants, fill styles, sizes, pending and
links work the same way.

## Quiet

`quiet` drops the fill and border until the pointer is over the button,
like Spectrum's quiet action button. Use it for actions repeated on every
row, in toolbars and in headers, where filled buttons would crowd the
content. `negative` and `accent` colour the icon.

</ExampleBlock>

## Sizes

24, 32, 40 and 48 px square, the same scale as every control. Use S in
dense tables, M (default) almost everywhere else.

## States

Hover, pressed, keyboard focus, disabled and pending, filled (top) and quiet
(bottom). Disabled doesn't react to hover or press. Pending replaces the
icon with a spinner and ignores presses.

## Accessibility

- `aria-label` is required: name the action (“Delete page”), not the icon
  (“Trash”). In a list, include the item: “Delete Admissions 2027”.
- Renders a native `<button type="button">` (or `<a>`), so Enter and Space
  work. Pass `aria-expanded`, `aria-controls` and `aria-haspopup` when it
  opens a menu, dialog or drawer.
- Every size is at least 24 × 24 px (WCAG 2.2 target size).
- Pending sets `aria-busy` and keeps the button focusable.
- Group related icon buttons in a `role="toolbar"` with a label.

## Props

| Prop                                              | Type                                                                | Default       |
| ------------------------------------------------- | ------------------------------------------------------------------- | ------------- |
| `icon`                                            | a lucide-solid icon; required                                       |               |
| `aria-label`                                      | `string`; required                                                  |               |
| `variant`                                         | `'accent' \| 'primary' \| 'secondary' \| 'negative' \| 'highlight'` | `'secondary'` |
| `fillStyle`                                       | `'bold' \| 'outline'`                                               | `'bold'`      |
| `quiet`                                           | `boolean`                                                           | `false`       |
| `size`                                            | `'s' \| 'm' \| 'l' \| 'xl'`                                         | `'m'`         |
| `staticColor`                                     | `'white' \| 'black'`                                                |               |
| `pending`                                         | `boolean`                                                           | `false`       |
| `disabled`                                        | `boolean`                                                           | `false`       |
| `href`, `target`, `rel`                           | `string`; `href` renders an `<a>`                                   |               |
| `type`                                            | `'button' \| 'submit' \| 'reset'`                                   | `'button'`    |
| `aria-expanded`, `aria-controls`, `aria-haspopup` | for buttons that open something                                     |               |
| `onClick`                                         | `(event: MouseEvent) => void`                                       |               |
