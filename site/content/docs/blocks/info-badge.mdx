A label and a value in an outlined box: “NAAC accredited / B+ grade”. Use `inverse` (default) on dark bands and photos, `subtle` on light surfaces, and `outline` for a transparent box with a dark hairline on a tinted band.

## Accessibility

- Plain text; the label and value read in order.

## Props

| Prop      | Type                    | Default     |
| --------- | ----------------------- | ----------- |
| `label`   | `string`                |             |
| `value`   | `string`                |             |
| `variant` | `'inverse' \| 'subtle' \| 'outline'` | `'inverse'` |
