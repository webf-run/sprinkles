A dropdown menu keeps secondary actions out of the way until they're needed:
a page's actions in the editor's toolbar, a row's actions in a table. Each
item does something when chosen.

To choose a value in a form, use a Select. For two or three actions, show
them as [Buttons](/actions/button/) instead; a menu hides them.

## Items

`items` is a list of entries. An item has a `value`, a `label`, and
optionally an `icon` and a `shortcut`. Choosing one calls the menu's
`onSelect` with its value (and the item's own `onSelect`, if it has one).

Shortcuts are only shown; bind the keys yourself.

## Groups and separators

`{ type: 'group', label, items }` puts items under a label;
`{ type: 'separator' }` draws a line. Use groups when a menu has more than
about seven items.

## States

Items highlight on hover and with the arrow keys, and darken while pressed.
A `disabled` item stays in place, greyed, so the menu doesn't change shape;
arrow keys skip it. A `negative` item is red and highlights in a red tint.

## Accessibility

- The trigger gets `aria-haspopup="menu"` and `aria-expanded`; the list is a
  `menu` of `menuitem`s, and groups are labelled by their label.
- Enter, Space or Arrow Down on the trigger opens the menu with the first
  item highlighted; Arrow Up opens it on the last.
- Arrow keys move between items, Home and End jump to the ends, and typing
  a letter jumps to the next item that starts with it.
- Enter or Space chooses an item and closes the menu; Escape or Tab closes it
  without choosing. Focus returns to the trigger.
- An icon-only trigger needs an `aria-label` that names what the actions
  apply to: “More actions for “About us””.

## Props

| Prop           | Type                                                              | Default          |
| -------------- | ----------------------------------------------------------------- | ---------------- |
| `trigger`      | `(props: TriggerProps) => JSX.Element`; required                  |                  |
| `items`        | `DropdownMenuEntry[]`; required                                   |                  |
| `onSelect`     | `(value: string) => void`                                         |                  |
| `placement`    | `'top' \| 'right' \| 'bottom' \| 'left'`, with `-start` or `-end` | `'bottom-start'` |
| `open`         | `boolean`; controlled                                             |                  |
| `defaultOpen`  | `boolean`                                                         | `false`          |
| `onOpenChange` | `(open: boolean) => void`                                         |                  |
| `class`        | `string`; added to the menu's panel                               |                  |

An item (`DropdownMenuItem`):

| Field      | Type                       |
| ---------- | -------------------------- |
| `value`    | `string`; required, unique |
| `label`    | `JSX.Element`; required    |
| `icon`     | a lucide-solid icon        |
| `shortcut` | `string`, such as `'⌘D'`   |
| `negative` | `boolean`                  |
| `disabled` | `boolean`                  |
| `onSelect` | `() => void`               |
