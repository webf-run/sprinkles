Ready-made sections that use [TimeField](/fields/time-field) for the time of
day: booking cards, search strips, admin tables and settings panels. Each one
changes the colour (`tone`), the fill (`outline`, `subtle` or `quiet`), the
size and the layout around the field, so you can start from the one closest to
your site. For every prop, see the [TimeField reference](/fields/time-field).
