A text area takes plain text that runs over more than a line: an excerpt, a
meta description, alt text, notes for reviewers. For one line, use a
[TextField](/fields/text-field). For formatted text (headings, links,
lists), use the rich text editor instead.

## Auto-resize

`rows` sets the starting height (3 by default). With `autoResize`, the text
area grows with its content instead of scrolling, and the resize handle goes
away.

## Character count

`maxLength` stops typing at the limit. Add `showCount` to show how much of it
is used, for text that is cut short elsewhere, like a meta description in
search results.

## Sizes

Text, padding and corner radius follow the same S, M, L and XL scale as the
other fields; the height comes from `rows`. M is the default.

## States

Hover darkens the outline; keyboard focus draws the focus ring. Invalid turns
the outline negative and shows `errorText`. Disabled is greyed out and skipped
by the Tab key. Read-only sits on a muted surface; it can be focused, selected
and copied.

</ExampleBlock>

## Accessibility

- A native `<textarea>`: Enter adds a line, Tab moves to the next field.
- The label names it, and the description or error describes it; see
  [Field](/fields/field).
- The count is visual only; screen readers already announce `maxLength`
  through the native attribute.

## Props

| Prop                                          | Type                                       | Default |
| --------------------------------------------- | ------------------------------------------ | ------- |
| `value`                                       | `string`                                   |         |
| `defaultValue`                                | `string`                                   |         |
| `onValueChange`                               | `(value: string) => void`                  |         |
| `rows`                                        | `number`                                   | `3`     |
| `autoResize`                                  | `boolean`; grows with its content          | `false` |
| `maxLength`                                   | `number`                                   |         |
| `showCount`                                   | `boolean`; needs `maxLength`               | `false` |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`                | `'m'`   |
| `placeholder`                                 | `string`                                   |         |
| `name`                                        | `string`                                   |         |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field)  |         |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                  | `false` |
| `id`                                          | `string`; the text area's id               |         |
| `aria-label`                                  | `string`; required without a visible label |         |
