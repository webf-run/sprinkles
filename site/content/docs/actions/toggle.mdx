A toggle is a button that stays pressed: Bold in the editor's toolbar,
“Pin to top” on a post. Pressing it again turns it off. It looks like a
secondary button while off and takes a bold neutral fill while on.

For an action that happens once (save, publish), use a
[Button](/actions/button). For a setting in a form, a Switch reads more
clearly as on/off.

## Accessibility

- Renders a native `<button>` with `aria-pressed`, so screen readers say
  “toggle button, pressed” or “not pressed”. Enter and Space toggle it.
- Name the setting, not the state: the label or `aria-label` is “Bold”,
  never “Bold on”. The pressed state is announced for you.
- Group related toggles in a `role="toolbar"` with a label.
- Every size is at least 24 × 24 px.

## Props

| Prop              | Type                               | Default |
| ----------------- | ---------------------------------- | ------- |
| `pressed`         | `boolean`; controlled state        |         |
| `defaultPressed`  | `boolean`; initial state           | `false` |
| `onPressedChange` | `(pressed: boolean) => void`       |         |
| `disabled`        | `boolean`                          | `false` |
| `size`            | `'s' \| 'm' \| 'l' \| 'xl'`        | `'m'`   |
| `quiet`           | `boolean`                          | `false` |
| `icon`            | a lucide-solid icon                |         |
| `children`        | the label                          |         |
| `aria-label`      | `string`; required without a label |         |
