A select picks from a short, fixed list: a page's status, its template, the
categories of a post. The options stay hidden until the trigger is pressed.
When the list is long enough that people would rather type than scroll (authors,
tags, pages), use a [Combobox](/fields/combobox/). For two or three options
that should all stay visible, use radio buttons.

## Single selection

Each option is `{ label, value, disabled? }`. The value is a string, or
`null` while nothing is selected. Pass `value` and `onValueChange` to control
it, or `defaultValue` to let the select keep it. With `name`, the value is
submitted with a plain form.

## Multiple selection

`multiple` lets people pick several options; the value is then a string array
and the list stays open between picks. The trigger lists the selected labels,
cut short with an ellipsis when they don't fit.

## Disabled options

An option with `disabled: true` stays in the list, greyed out, so people can
see it exists. Say why in its label or in the description.

## Sizes

S, M, L and XL are 24, 32, 40 and 48 px tall, like every other control; the
options in the list follow the trigger's size. M is the default; use S only in
dense tables and toolbars.

## States

Hover darkens the outline; keyboard focus draws the focus ring; while the list
is open, the highlighted option is tinted. Invalid outlines the trigger in the
negative colour and shows `errorText`. Disabled can't be opened. Read-only
shows the value on a muted surface and can't be opened, but stays focusable so
it can be read and copied.

## Accessibility

- Built on Ark UI's select: the trigger has `role="combobox"`, the list
  `role="listbox"`, and each option `role="option"` with `aria-selected`.
- Keyboard: Enter, Space or the arrow keys open the list; the arrow keys,
  Home and End move the highlight; typing jumps to the first option that
  starts with those letters; Enter or Space picks; Escape closes and returns
  focus to the trigger.
- The visible label names the trigger (`aria-labelledby`), and the
  description or error text describes it (`aria-describedby`). Without a
  label, pass `aria-label`.
- A hidden native `<select>` carries `name`, `required` and the value, so
  forms and browser autofill work without JavaScript glue.

## Props

| Prop                                          | Type                                                          | Default        |
| --------------------------------------------- | ------------------------------------------------------------- | -------------- |
| `items`                                       | `{ label: string; value: string; disabled?: boolean }[]`      |                |
| `multiple`                                    | `boolean`                                                     | `false`        |
| `value`                                       | `string \| null`; `string[]` with `multiple`                  |                |
| `defaultValue`                                | `string \| null`; `string[]` with `multiple`                  |                |
| `onValueChange`                               | `(value: string \| null) => void`; `string[]` with `multiple` |                |
| `placeholder`                                 | `string`                                                      |                |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`                                   | `'m'`          |
| `name`                                        | `string`; submits the value with a form                       |                |
| `emptyText`                                   | `JSX.Element`; shown when `items` is empty                    | `'No options'` |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field/)                    |                |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                                     | `false`        |
| `id`                                          | `string`; the field's control id                              |                |
| `aria-label`                                  | `string`; required without a visible label                    |                |
