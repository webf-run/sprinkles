A file upload takes files from people's devices: a featured image, a PDF to
attach. They drop files on the dropzone or press it to pick them; each file is
then listed with its size and a remove button. It only collects `File`
objects; uploading them is up to you. To pick from files already in the media
library, use the media picker instead.

## Several files

`maxFiles` is 1 by default, and a new file replaces the old one. Raise it to
collect several; the value is always a `File[]`. With `name`, the files are
submitted with a plain multipart form.

<ExampleBlock code={multipleCode}>
  <MultipleOutput client:load />
</ExampleBlock>

## Types and size limits

`accept` takes MIME types (`'image/*'`, `'application/pdf'`) or extensions
(`'.docx'`), and `maxFileSize` a size in bytes. Files that break a rule are
listed with the reason, so people know what to fix; remove them from the list
or add another file. Say the rules up front in `hint`.

## States

Hover tints the dropzone; dragging files over it fills it with the accent
colour; keyboard focus draws the focus ring. Invalid outlines it in the
negative colour and shows `errorText`. Disabled can't take files. Read-only
hides the dropzone and the remove buttons and only lists the files.

## Accessibility

- Built on Ark UI's file upload: the dropzone is a `role="button"`, named by
  the field's label and its instruction, and opens the file picker with Enter
  or Space. Dropping is never the only way in.
- A hidden native `<input type="file">` holds the files, so `accept` and
  forms work as usual.
- Each remove button is labelled with the file's name.
- Rejected files say why in text, not only in colour.

## Props

| Prop                                          | Type                                           | Default |
| --------------------------------------------- | ---------------------------------------------- | ------- |
| `value`                                       | `File[]`                                       |         |
| `defaultValue`                                | `File[]`                                       |         |
| `onValueChange`                               | `(files: File[]) => void`                      |         |
| `accept`                                      | `string \| string[]`; MIME types or extensions |         |
| `maxFiles`                                    | `number`                                       | `1`     |
| `maxFileSize`                                 | `number`; bytes                                |         |
| `hint`                                        | `JSX.Element`; shown in the dropzone           |         |
| `name`                                        | `string`                                       |         |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field)      |         |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                      | `false` |
| `id`                                          | `string`; the hidden file input's id           |         |
