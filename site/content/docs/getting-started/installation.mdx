Sprinkles is a [Solid.js](https://www.solidjs.com) component library styled
with Tailwind CSS. It works anywhere Solid works: **Astro**, **SolidStart** or
a plain **Vite + Solid.js** app. The package is the same in all three; only the
setup around it differs.

## Requirements

- Node.js 20 or later
- A Solid.js 1.9 project that uses [Vite](https://vite.dev) (Astro and
  SolidStart both do)
- npm, pnpm, yarn or bun

## Install the package

Sprinkles needs `solid-js` as a peer dependency. Your project already has it
if it is a Solid project.

```bash
# npm
npm install @webf/sprinkles

# pnpm
pnpm add @webf/sprinkles

# yarn
yarn add @webf/sprinkles

# bun
bun add @webf/sprinkles
```

## Set up your framework

Sprinkles ships its JSX uncompiled, so your app's own Solid setup compiles it.
That is how one build works for client rendering, server rendering and
hydration. Pick your framework for the exact steps.

| You are using                         | Read                                        |
| ------------------------------------- | ------------------------------------------- |
| Astro                                 | [Astro](/getting-started/astro/)            |
| SolidStart                            | [SolidStart](/getting-started/solid-start/) |
| Vite with Solid.js, no meta-framework | [Vite + Solid.js](/getting-started/vite/)   |

## Load the styles

Every setup needs one stylesheet, and there are two ways to get it:

|                 | Precompiled                         | Tailwind CSS v4                              |
| --------------- | ----------------------------------- | -------------------------------------------- |
| Import          | `@webf/sprinkles/style.css`         | `@webf/sprinkles/theme.css`                  |
| Needs Tailwind  | No                                  | Yes, v4                                      |
| Resets your CSS | No                                  | Only if you import `tailwindcss` (Preflight) |
| Best for        | Apps without Tailwind, quick starts | Apps that already use Tailwind               |

[Styling and theming](/getting-started/styling/) explains both, and how to
switch on dark mode.

## Try a component

Once your framework is set up, render a component:

```tsx
import { Link } from '@webf/sprinkles';

export function Hello() {
  return <Link href='/getting-started/styling/'>Hello Sprinkles</Link>;
}
```

It renders as:

<Link href='/getting-started/styling/'>Hello Sprinkles</Link>
