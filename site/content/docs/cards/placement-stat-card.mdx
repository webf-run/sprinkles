`PlacementStatCard` combines a high-level outcome number with a short title and contextual note. It is designed for placement, careers, and results sections.

## Props

| Prop       | Type                                                                                                        | Default     | Description                    |
| ---------- | ----------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------ |
| `icon`     | `AstroComponent`                                                                                            | —           | Lucide icon component.         |
| `value`    | `string`                                                                                                    | —           | Outcome value.                 |
| `title`    | `string`                                                                                                    | —           | Metric heading.                |
| `subtitle` | `string`                                                                                                    | —           | Supporting detail.             |
| `variant`  | `'default' \| 'accent' \| 'surface' \| 'inverse' \| 'purple' \| 'orange' \| 'green' \| 'blue' \| 'neutral'` | `'default'` | Token-based color treatment.   |
| `size`     | `'sm' \| 'md' \| 'lg'`                                                                                      | `'md'`      | Card spacing scale.            |
| `effect`   | `'none' \| 'lift' \| 'glow'`                                                                                | `'none'`    | Hover effect.                  |
| `class`    | `string`                                                                                                    | —           | Additional Tailwind utilities. |
