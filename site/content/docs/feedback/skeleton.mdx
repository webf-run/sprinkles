Skeletons stand in for content that's on its way: the rows of a page list,
a media card, a profile. Because they take the content's shape, the layout
doesn't jump when it arrives, and people can see what's coming.

For a wait that has no layout to hold (saving, a short upload), use a
[Spinner](/feedback/spinner/).

## Shapes

`shape='text'` (default) draws `lines` bars, spaced like `text-sm`; the last
of several is shorter, like the end of a paragraph. `circle` is 40 px and
`rect` is 96 px tall by default. Set any size with `class`.

## Loading a list

## States

Skeletons pulse gently (`animate-shimmer`, 1.6 s). With reduced motion they
hold still.

## Accessibility

- Skeletons are `aria-hidden`: a screen reader hears nothing for each grey
  bar.
- Set `aria-busy="true"` on the region that's loading, and remove it when the
  content is in, so assistive technology waits and then reads the result.
- For a wait longer than a few seconds, also announce it, for example with a
  visually hidden “Loading pages” in a polite live region.

## Props

| Prop    | Type                           | Default  |
| ------- | ------------------------------ | -------- |
| `shape` | `'text' \| 'circle' \| 'rect'` | `'text'` |
| `lines` | `number`; for `text`           | `1`      |
| `class` | `string`; sets the size        |          |
