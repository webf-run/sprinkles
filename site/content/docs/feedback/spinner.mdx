A spinner says “working on it” for a wait of unknown length: loading a
preview, uploading a file. Buttons show one by themselves while
[pending](/actions/button#states).

When the content's layout is known (a list, a card), a
[Skeleton](/feedback/skeleton) is better: it holds the layout and hints at
what's coming.

## Sizes

S, M, L and XL are 16, 24, 32 and 48 px. M is the default; S fits inside a
line of text or a control.

<ExampleBlock code={sizesCode}>
  <SizesOutput />
</ExampleBlock>

## Colour

`tone='accent'` (default) uses the accent colour. `tone='current'` follows
the text colour, for a spinner inside a button or a coloured message. Over
photos or a dark band, `staticColor='white'` or `'black'` ignores the theme.

</ExampleBlock>

## In context

## States

The arc turns once a second. With reduced motion it holds still; the arc
still reads as “in progress”.

## Accessibility

- Rendered as `role="progressbar"` without a value, which screen readers
  announce as busy or indeterminate progress.
- `label` names what's loading (“Loading pages”); it defaults to “Loading”.
  Make it specific when more than one thing can load at once.
- A spinner that appears after the page has loaded isn't announced by
  itself. For a long wait, also say so in a polite live region, or set
  `aria-busy` on the region that's updating.

## Props

| Prop          | Type                             | Default     |
| ------------- | -------------------------------- | ----------- |
| `size`        | `'s' \| 'm' \| 'l' \| 'xl'`      | `'m'`       |
| `label`       | `string`; read by screen readers | `'Loading'` |
| `tone`        | `'accent' \| 'current'`          | `'accent'`  |
| `staticColor` | `'white' \| 'black'`             |             |
| `class`       | `string`                         |             |
