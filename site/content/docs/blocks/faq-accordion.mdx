A stack of questions on native `<details>`, so it works without JavaScript and can be rendered on the server with no hydration.

## Basic

By default one answer is open at a time (`exclusive`); set `exclusive={false}` to let several stay open.

<ExampleBlock code={basicCode}>

</ExampleBlock>

## Accessibility

- Native `<details>` and `<summary>`: Enter and Space toggle, and screen readers announce expanded or collapsed.
- Keyboard focus shows the focus ring on the question.

## Props

| Prop        | Type                                     | Default   |
| ----------- | ---------------------------------------- | --------- |
| `items`     | `{ question: string; answer: string }[]` |           |
| `exclusive` | `boolean`                                | `true`    |
| `name`      | `string`; the group name for `exclusive` | generated |
