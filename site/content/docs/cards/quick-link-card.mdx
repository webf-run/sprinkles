A quick link card sends visitors straight to a page they came for:
the steps to apply, the timetable, the price list. The whole card is the
link's target and lifts on hover. It shares its look with the other cards:
the same `variant` and `fillStyle`.

## Variant and fill style

`variant` takes a tone (`accent` by default) and `fillStyle` how strongly it
shows: `outline` (default) colours only the chip, `subtle` tints the card,
and `bold` fills it. See [TestimonialCard](/cards/testimonial-card#variants)
for the full list of tones.

## States

Hover lifts the card and, in the outline style, tints its border; pressing
sets it back down. Keyboard focus lands on the title link and draws the
focus ring around the whole card. Motion is off when the visitor prefers
reduced motion.

## Accessibility

- Renders an `<article>` with an `<h3>` title. The title is the only link,
  so a screen reader announces just the title, not the whole card; a
  pseudo-element stretches its target over the card.
- The step number is read before the title; an icon chip is hidden from
  screen readers.
- Write titles that name the destination, since they are what link lists
  and screen readers show.

## Props

| Prop          | Type                                                | Default     |
| ------------- | --------------------------------------------------- | ----------- |
| `title`       | `string`                                            |             |
| `href`        | `string`                                            |             |
| `description` | `string`                                            |             |
| `step`        | `string`; a number or short label in the chip       |             |
| `icon`        | a lucide-solid icon; replaces `step`                |             |
| `variant`     | a tone: a role, `highlight` or a categorical colour | `'accent'`  |
| `fillStyle`   | `'outline' \| 'subtle' \| 'bold'`                   | `'outline'` |
| `class`       | `string`                                            |             |
