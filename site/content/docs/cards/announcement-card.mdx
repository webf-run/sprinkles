`AnnouncementCard` spotlights one announcement with its date and a call to action. `AnnouncementListItem` is a row of the list beside it.

## Accessibility

- The title is an `<h3>`; the eyebrow and date are text, not headings.
- The icon tile is hidden from screen readers.

## Props

| Prop                                              | Type                | Default |
| ------------------------------------------------- | ------------------- | ------- |
| `icon`                                            | a lucide-solid icon |         |
| `eyebrow, caption, tag (card)`                    | `string`            |         |
| `title, subtitle, description`                    | `string`            |         |
| `dateLabel, date, actionLabel, actionHref (card)` | `string`            |         |
| `category, title, description, date (list item)`  | `string`            |         |
