FooterColumns closes a page with a map of the site: the brand on one side,
titled columns of links on the other. It suits sites with many pages, such
as a college or a shop. For a footer built around contact details, use
[Footer](/blocks/footer/); both share the same surfaces, brand and last row.

The footer is laid out by its own width: the columns sit two to a row when
narrow, three from 36rem, and beside the brand from 56rem.

## Columns

`columns` is a list of `{ title, links }`. A link without `href` is shown as
plain text, for an address or opening hours in the same grid. Three to five
columns of three to six links read best.

</ExampleBlock>

## Surface

`surface` works as in [Footer](/blocks/footer/#surface): `default` (with a
divider above), `muted`, or `inverse` for a dark band.

## Accessibility

- Renders a `<footer>` (the content-info landmark), with the columns in one
  `<nav>` named by `label` (“Footer” by default).
- Column titles are `<h2>`s, so they fit after the page's own sections.
- Social links show only an icon, so `label` is required: it's the link's
  accessible name. Each is 40 × 40 px.
- Text and links pass 4.5:1 contrast on all three surfaces.

## Props

| Prop          | Type                                             | Default     |
| ------------- | ------------------------------------------------ | ----------- |
| `columns`     | `FooterColumn[]`                                 |             |
| `surface`     | `'default' \| 'muted' \| 'inverse'`              | `'default'` |
| `logoText`    | `string`; also the logo image's alt text         |             |
| `logoSrc`     | `string`                                         |             |
| `logo`        | `JSX.Element`; replaces `logoSrc` and `logoText` |             |
| `description` | `string`                                         |             |
| `socialLinks` | `FooterSocial[]` (see [Footer](/blocks/footer/)) |             |
| `year`        | `number`                                         | this year   |
| `copyright`   | `string`; follows “© year”                       |             |
| `label`       | `string`; names the `<nav>`                      | `'Footer'`  |
| `class`       | `string`                                         |             |

### FooterColumn

| Field   | Type                                                          |
| ------- | ------------------------------------------------------------- |
| `title` | `string`                                                      |
| `links` | `{ label: string; href?: string }[]`; no `href` is plain text |
