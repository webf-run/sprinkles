A benefit card lists the reasons behind one claim: a title, then two to four short points. It shares the [Feature Card](/cards/feature-card)'s `variant`, `fillStyle` and `size`.

## Basic

An icon in a chip, a title, and the points with check marks.

<ExampleBlock code={basicCode}>
  <BasicOutput />
</ExampleBlock>

## Fill style

`outline` (default), `subtle` and `bold`, as on every marketing card. Text colour is set on the card and inherited, so one `class` recolours it.

<ExampleBlock code={fillStylesCode}>
  <FillStylesOutput />
</ExampleBlock>

## Icon and markers

`iconBackground={false}` shows the icon without its chip (size it with `iconClass`). `marker='dot'` replaces the checks with dots, for points that aren't claims to tick off.

<ExampleBlock code={markersCode}>
  <MarkersOutput />
</ExampleBlock>

## Accessibility

- The points are a real `<ul>`, so screen readers announce how many there are.
- Markers and the icon are hidden from screen readers.

## Props

| Prop                                 | Type                                           | Default     |
| ------------------------------------ | ---------------------------------------------- | ----------- |
| `title`                              | `string`                                       |             |
| `bullets`                            | `string[]`                                     |             |
| `icon`                               | a lucide-solid icon                            |             |
| `variant`                            | a role, `'highlight'`, or a categorical colour | `'accent'`  |
| `fillStyle`                          | `'outline' \| 'subtle' \| 'bold'`              | `'outline'` |
| `size`                               | `'s' \| 'm' \| 'l'`                            | `'m'`       |
| `iconBackground`                     | `boolean`                                      | `true`      |
| `marker`                             | `'check' \| 'dot'`                             | `'check'`   |
| `titleClass, bulletClass, iconClass` | `string`                                       |             |
