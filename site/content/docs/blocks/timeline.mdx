A timeline tells a story in order. Each entry has a short label, such as a year, a time or a week, and a sentence about what happened. Visitors can scan the labels, then read only the moments they care about. Choose a [layout](#layouts) to match the space you have and a [colour](#colours) to match your brand. It is plain markup, so it can be rendered on the server with no hydration.

## Basic

Pass `items`, each with a `label` and the `text` that goes with it. Entries appear in the order you give them. The `class` prop sets the width, so the timeline fits wherever you place it. With no other props you get the `vertical` layout in the `accent` colour.

## Layouts

The `layout` prop changes how the entries are arranged. The words stay the same, so each layout below shows the same four moments. Pick the one that fits the room you have.

| Layout        | Looks like                                           | Fits                                        |
| ------------- | ---------------------------------------------------- | ------------------------------------------- |
| `vertical`    | A rail on the left, entries stacked beside it        | Narrow columns, about pages, order status   |
| `split`       | Labels in a column on the left, text beside the rail | Schedules, CVs and changelogs               |
| `alternating` | A centred rail, entries on both sides                | A company story across a full-width section |
| `horizontal`  | Entries side by side along a line                    | Roadmaps and a few short steps              |
| `cards`       | Each entry in its own card                           | Courses, features and seasons               |

`alternating` and `horizontal` need room. They follow the width of the timeline itself, not the window's, so on a narrow container they fall back to the `vertical` layout and nothing is cut off. `cards` shows two columns, then one row when there is room.

## Colours

The `variant` prop sets the colour of the labels and markers. It takes any of the library's tones: the roles (`accent`, `neutral`, `informative`, `positive`, `notice`, `negative`), `highlight`, and the categorical colours (`seafoam`, `indigo`, `purple`, `fuchsia`, `yellow`). The default is `accent`. Tones are semantic tokens, so a site that re-skins its tokens re-skins its timelines too, and each one looks right in the light and the dark scheme.

| Tone                  | Mood              | Fits                               |
| --------------------- | ----------------- | ---------------------------------- |
| `accent`              | Your brand colour | Any site, and the safe default     |
| `informative`         | Calm blue         | Software, finance, public services |
| `positive`, `seafoam` | Fresh green       | Charities, health, deliveries      |
| `notice`, `highlight` | Warm orange       | Food, retail, events               |
| `indigo`, `purple`    | Deep and creative | Courses, studios, technology       |
| `fuchsia`             | Bold and playful  | Fashion, youth and entertainment   |
| `neutral`             | Quiet grey        | CVs, law, editorial sites          |

## Writing good entries

- Keep labels short: a year, a time or a few words. They are set in a large size.
- Write one sentence for each entry, or two at the most.
- Use the same kind of label throughout: all years, all times or all weeks.
- Three to six entries read best. For a longer history, show the key moments and link to the full story.
- Use one colour for each timeline. Let the layout, not a rainbow, carry the variety.

## Accessibility

- It is an ordered list (`<ol>`), so screen readers announce how many entries there are and which one they are on.
- The markers are decorative and hidden from assistive technology. Everything that matters is in the label and the text.
- Put the entries in the order you want them read, usually oldest first. A roadmap reads best soonest first. The `alternating` layout keeps the same reading order as the list.
- The numbers inside markers use the tone's own pair of colours, which `pnpm check:tokens` checks at 4.5:1. Label colours also reach 4.5:1 on the `surface` and `surface-muted` backgrounds, in both schemes, and `pnpm check:tokens` checks them too. On the tinted `surface-tint`, check the `positive` tone, which is 4.4:1. Dark backgrounds use white text on `surface-inverse`.

## Props

| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| `items`   | `{ label: string; text: string }[]`                                                                                                                                          |            |
| `layout`  | `'vertical'`, `'split'`, `'alternating'`, `'horizontal'` or `'cards'`                                                                                                        | `vertical` |
| `variant` | `'accent'`, `'neutral'`, `'informative'`, `'positive'`, `'notice'`, `'negative'`, `'highlight'`, `'seafoam'`, `'indigo'`, `'purple'`, `'fuchsia'`, `'yellow'` or `'inverse'` | `accent`   |
