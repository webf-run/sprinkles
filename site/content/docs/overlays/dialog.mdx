A dialog opens over the page for a task that needs full attention and has a
clear end: renaming a page, editing its settings, moving an image. The page
behind is dimmed and can't be used until the dialog closes.

To confirm or cancel a single action (delete, publish, overwrite), use an
[AlertDialog](/overlays/alert-dialog/). For a small form or details that
shouldn't hide the page, use a [Popover](/overlays/popover/).

## With a trigger

`trigger` renders the element that opens the dialog. It receives the props
Ark needs (ARIA attributes, the click handler): spread them on a
[Button](/actions/button/). Give `footer` a function to get `close` for the
Cancel button.

## Controlled

Pass `open` and `onOpenChange` to open the dialog from your own code, for
example from a menu item or after a check. `onOpenChange(false)` fires for
Escape, the close button and a click on the backdrop.

## Sizes

`size` sets the maximum width: S, M and L are 384, 512 and 672 px. M is the
default; use S for a single field and L for a table or a preview. On small
screens every size fills the width, less a 16 px margin.

## States

- **Opening:** the backdrop fades in and the dialog pops in (200 ms). Focus
  moves to the first field or button in the body, then the footer; the close
  button comes last.
- **Closing:** both fade out (100 ms), the content unmounts, and focus
  returns to the trigger, or to whatever had focus before.
- **Reopening:** the body and footer are created afresh, so a form starts
  from its default values.
- **Reduced motion:** no fade or scale; it appears and disappears at once.

## Accessibility

- Rendered with `role="dialog"` and `aria-modal="true"`; the title and the
  description label and describe it.
- Focus is trapped inside while it's open: Tab and Shift+Tab cycle through
  its controls. The page behind is hidden from screen readers and doesn't
  scroll.
- Escape closes it (unless `closeOnEscape={false}`), as do the close button
  and a click on the backdrop (unless `closeOnInteractOutside={false}`).
- The close button is labelled “Close”, is 32 × 32 px, and is last in the
  tab order so focus starts on the task.

## Props

| Prop                     | Type                                                  | Default    |
| ------------------------ | ----------------------------------------------------- | ---------- |
| `title`                  | `JSX.Element`; required                               |            |
| `description`            | `JSX.Element`                                         |            |
| `children`               | `JSX.Element`; the body                               |            |
| `footer`                 | `JSX.Element \| ((close: () => void) => JSX.Element)` |            |
| `size`                   | `'s' \| 'm' \| 'l'`                                   | `'m'`      |
| `trigger`                | `(props: TriggerProps) => JSX.Element`                |            |
| `open`                   | `boolean`; controlled                                 |            |
| `defaultOpen`            | `boolean`                                             | `false`    |
| `onOpenChange`           | `(open: boolean) => void`                             |            |
| `dismissable`            | `boolean`; shows the close button                     | `true`     |
| `closeOnEscape`          | `boolean`                                             | `true`     |
| `closeOnInteractOutside` | `boolean`                                             | `true`     |
| `role`                   | `'dialog' \| 'alertdialog'`                           | `'dialog'` |
| `class`                  | `string`; added to the dialog's panel                 |            |
