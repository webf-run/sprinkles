A tile that frames an icon beside a heading or list item. `variant='inverse'` is the dark tile of `surface-inverse`; any tone works with `fillStyle` `bold` (default) or `subtle`.

## Accessibility

- Decorative: hidden from screen readers (`aria-hidden`).

## Props

| Prop        | Type                                 | Default     |
| ----------- | ------------------------------------ | ----------- |
| `icon`      | a lucide-solid icon                  |             |
| `variant`   | a tone, or `'inverse'`               | `'neutral'` |
| `fillStyle` | `'bold' \| 'subtle'`                 | `'bold'`    |
| `size`      | `'m' \| 'l' \| 'xl'` (40, 48, 56 px) | `'l'`       |
