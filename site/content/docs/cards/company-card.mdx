`CompanyLogoCard` presents partner, customer, or employer logos in an even responsive grid. It renders as a non-interactive card by default, and becomes a safely labelled external link when `href` is provided.

## Logo grid

The basic example demonstrates how to display multiple company logos using `CompanyLogoCard`. Each card accepts a logo, company name, and optional styling props. The cards can be placed in a responsive grid to create a clean logo wall.

## Props

| Prop          | Type                                                                                         | Default     | Description                                    |
| ------------- | -------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------- |
| `logo`        | `string \| AstroComponent`                                                                   | —           | Image URL, local asset path, or SVG component. |
| `companyName` | `string`                                                                                     | —           | Accessible company name for the logo.          |
| `href`        | `string`                                                                                     | —           | Optional external destination.                 |
| `variant`     | `'default' \| 'muted' \| 'accent' \| 'purple' \| 'orange' \| 'green' \| 'blue' \| 'neutral'` | `'default'` | Token-based color treatment.                   |
| `size`        | `'sm' \| 'md' \| 'lg'`                                                                       | `'md'`      | Card dimensions.                               |
| `effect`      | `'none' \| 'lift' \| 'scale'`                                                                | `'scale'`   | Hover effect.                                  |
| `class`       | `string`                                                                                     | —           | Additional Tailwind utilities.                 |
