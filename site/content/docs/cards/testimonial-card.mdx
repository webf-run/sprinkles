`TestimonialCard` pairs a quote with the person who said it. It works as a
single highlighted quote or repeated in a grid, and it carries no
site-specific copy so it drops into a marketing page, a product changelog,
or a review section on any theme.

## Basic

Use the basic example when you need to display a simple customer testimonial
with the quote, person's name, and role. This is the simplest way to introduce
a testimonial without additional visual options.

## Sizes

The size option controls the spacing and typography of the testimonial card.
Use `sm` for compact layouts, `md` for the default layout, and `lg` when the
testimonial needs more visual emphasis.

## Avatar and rating

Use the avatar option when you want to show the testimonial author's image.
The optional rating can be added independently to display a 0–5 star rating.
Both options can also be omitted when a text-focused testimonial is preferred.

## Props

| Prop      | Type                                                                                                      | Default     | Description                        |
| --------- | --------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------- |
| `quote`   | `string`                                                                                                  | —           | The testimonial text.              |
| `name`    | `string`                                                                                                  | —           | Name of the person quoted.         |
| `role`    | `string`                                                                                                  | —           | Their role, title, or affiliation. |
| `avatar`  | `string`                                                                                                  | —           | Optional avatar image URL.         |
| `rating`  | `number`                                                                                                  | —           | Optional star rating from 0–5.     |
| `variant` | `'default' \| 'muted' \| 'accent' \| 'inverse' \| 'purple' \| 'orange' \| 'green' \| 'blue' \| 'neutral'` | `'default'` | Token-based color treatment.       |
| `size`    | `'sm' \| 'md' \| 'lg'`                                                                                    | `'md'`      | Card spacing and type scale.       |
| `effect`  | `'none' \| 'lift' \| 'glow'`                                                                              | `'none'`    | Hover effect.                      |
| `class`   | `string`                                                                                                  |
