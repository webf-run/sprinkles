An empty state fills the space where content would be: a site with no pages
yet, a search with no results, an empty media folder. It says what's empty
and, where it can, offers the action that fills it.

## Sizes

`size='m'` (default) is for a whole page or a large panel. `size='s'` is
tighter, for a table body, a card or a sidebar.

## Accessibility

- The heading is an `<h3>` by default; set `headingLevel` so it fits the
  page's outline.
- The icon and the illustration are decorative and hidden from screen
  readers; the heading carries the meaning.
- When the empty state replaces results after a search, announce the change
  (for example in a polite live region): “No results for pricing”.

## Props

| Prop           | Type                             | Default |
| -------------- | -------------------------------- | ------- |
| `heading`      | `JSX.Element`; required          |         |
| `headingLevel` | `2 \| 3 \| 4`                    | `3`     |
| `description`  | `JSX.Element`                    |         |
| `icon`         | a lucide-solid icon              |         |
| `illustration` | `JSX.Element`; replaces the icon |         |
| `actions`      | `JSX.Element`; Buttons           |         |
| `size`         | `'s' \| 'm'`                     | `'m'`   |
| `class`        | `string`                         |         |
