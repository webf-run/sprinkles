The `Navbar` component provides a single, reusable navigation bar you can drop into any Astro site — marketing pages, docs portals, dashboards, or auth screens — and configure per page. It supports branding through a text logo, an image logo, or a fully custom logo mark, configurable navigation links with optional dropdown indicators, and a flexible call-to-action area for one or more buttons.

`Navbar` is responsive out of the box. On medium screens and up (`md:` / 768px and wider) navigation links render inline next to the logo. Below that breakpoint the links move into a hamburger menu, opened with the trigger button that appears next to your call-to-action buttons. The menu closes automatically when a link inside it is clicked, when you click outside it, when you press <kbd>Escape</kbd>, or when the viewport is resized back past the `md` breakpoint — no extra configuration required. Resize the examples below, or view them on a small screen, to see the mobile menu in action.

Use the interactive playgrounds below to experiment with different navbar configurations and see the output update in real time.

## Positioning

By default `Navbar` renders with `position='fixed'`, pinning it to the top of the viewport — the right choice for most real pages. The examples on this page all pass `position='static'` instead, purely so the navbar stays inside its preview frame rather than covering the rest of the docs page. In your own app, choose whichever fits the layout:

- `fixed` (default) — pinned to the top of the viewport, stays in place while the page scrolls underneath it.
- `sticky` — scrolls with the page until it reaches the top, then sticks.
- `static` — flows normally in the document, scrolling away with the rest of the page.

## Props

| Prop       | Type                              | Default   | Description                                                                        |
| ---------- | --------------------------------- | --------- | ---------------------------------------------------------------------------------- |
| `logoSrc`  | `string`                          | —         | URL of a logo image. Ignored if the `logo` slot is used.                           |
| `logoText` | `string`                          | —         | Text logo, rendered when `logoSrc` is not set. Ignored if the `logo` slot is used. |
| `navItems` | `NavItem[]`                       | `[]`      | Navigation links rendered on desktop and inside the mobile menu.                   |
| `class`    | `string`                          | —         | Applied to every navigation link.                                                  |
| `style`    | `string`                          | —         | Inline style applied to the `<nav>` element.                                       |
| `position` | `'fixed' \| 'sticky' \| 'static'` | `'fixed'` | Controls how the navbar is positioned relative to the page.                        |

### NavItem

| Field         | Type      | Description                                                             |
| ------------- | --------- | ----------------------------------------------------------------------- |
| `label`       | `string`  | Text shown for the link.                                                |
| `href`        | `string`  | Destination URL.                                                        |
| `hasDropdown` | `boolean` | Shows a chevron indicator next to the label. Optional, default `false`. |

### Slots

| Slot      | Description                                                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `logo`    | Replaces the default `logoSrc` / `logoText` rendering entirely.                                                                      |
| `actions` | Replaces the default "Apply Now" button. Use it to render one or more `Link` components, for example a "Login" and "Apply Now" pair. |
