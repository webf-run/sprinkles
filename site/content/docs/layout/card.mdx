```tsx
import { Card, CardBody, CardFooter, CardHeader } from '@webf/sprinkles';
```

A card groups content about one subject on its own surface: a dashboard
figure, a group of settings, a shortcut to a section. Compose a
`CardHeader`, `CardBody` and `CardFooter` inside; each is padded, and the
card spaces them evenly.

The marketing cards in [Cards](/cards/feature-card) are for websites; this
one is the admin's plain container. To separate parts of one card, use a
[Separator](/layout/separator), not another card.

## As a link

With `href`, the whole card is one link: its edge darkens and it lifts on
hover, and it shows the focus ring on keyboard focus. The link's name is the
card's text, so keep it short, or give the card an `aria-label`.

## Accessibility

- An unlinked card is a `<div>`; pass `as='article'` for self-contained
  content or `as='li'` inside a list of cards.
- The title is a real heading (`h3` by default). Set `headingLevel` so the
  page's outline has no gaps.
- A linked card is a single `<a>`. Don't put buttons or other links inside
  it: nested controls are invalid HTML and unreachable for many users.
- A list of linked cards belongs in a `<ul>`, so screen readers announce how
  many there are.

## Props

### Card

| Prop                    | Type                                                 | Default |
| ----------------------- | ---------------------------------------------------- | ------- |
| `as`                    | `'div' \| 'article' \| 'section' \| 'li'` (unlinked) | `'div'` |
| `elevated`              | `boolean`                                            | `false` |
| `href`, `target`, `rel` | `string`; `href` makes the card one link             |         |
| `aria-label`            | `string`; names a linked card                        |         |

### CardHeader

| Prop           | Type                          | Default |
| -------------- | ----------------------------- | ------- |
| `title`        | `JSX.Element`                 |         |
| `description`  | `JSX.Element`                 |         |
| `actions`      | `JSX.Element`                 |         |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6`       | `3`     |
| `children`     | extra content under the title |         |

`CardBody` and `CardFooter` take `class` and `children`.
