A date picker takes one date: a publish date, an event date, a deadline.
People type it in their own format or pick it from a calendar. The value goes
in and out as ISO text (`YYYY-MM-DD`), the way the CMS stores dates.

## Value

`value`, `defaultValue` and `onValueChange` use ISO dates, `'2027-03-14'`, or
`null` for no date. Typed dates are read in the locale's format (set `locale`
to change it) and handed back as ISO. With `name`, the ISO date is submitted
with a form, not the formatted text.

## Minimum and maximum

`min` and `max`, also ISO dates, grey out the days outside the range in the
calendar and stop the month navigation at its ends.

## Sizes

The input follows the same S, M, L and XL scale as the other fields (24 to
48 px tall). The calendar keeps one size, with 36 px days. M is the default.

## States

Hover darkens the outline; keyboard focus draws the focus ring on the input,
the calendar button and each day. In the calendar, today is bold and accent;
the selected day is filled. Invalid turns the outline negative and shows
`errorText`. Disabled and read-only can't open the calendar.

## Accessibility

- Built on Ark UI's date picker: the calendar is a `role="grid"`, labelled
  with the visible month, and each day says its full date, for example
  "Friday, November 20, 2026".
- Keyboard in the calendar: the arrow keys move by a day or a week; Page Up and
  Page Down by a month; Home and End to the start and end of the week; Enter
  picks; Escape closes and returns focus.
- The input accepts typed dates, so the calendar is never the only way in.
- The calendar button and the previous and next buttons are labelled for
  screen readers.

## Props

| Prop                                          | Type                                       | Default             |
| --------------------------------------------- | ------------------------------------------ | ------------------- |
| `value`                                       | `string \| null`; ISO date                 |                     |
| `defaultValue`                                | `string \| null`; ISO date                 |                     |
| `onValueChange`                               | `(value: string \| null) => void`          |                     |
| `min`                                         | `string`; ISO date                         |                     |
| `max`                                         | `string`; ISO date                         |                     |
| `locale`                                      | `string`; BCP 47 tag                       | `'en-US'`           |
| `placeholder`                                 | `string`                                   | the locale's format |
| `size`                                        | `'s' \| 'm' \| 'l' \| 'xl'`                | `'m'`               |
| `name`                                        | `string`; submits the ISO date             |                     |
| `label`, `description`, `errorText`           | `JSX.Element`; see [Field](/fields/field/) |                     |
| `required`, `invalid`, `disabled`, `readOnly` | `boolean`                                  | `false`             |
| `id`                                          | `string`; the input's id                   |                     |
| `aria-label`                                  | `string`; required without a visible label |                     |
