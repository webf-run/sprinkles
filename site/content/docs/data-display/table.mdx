```tsx
import { TBody, TCell, TH, THead, TRow, Table } from '@webf/sprinkles';
```

The table parts style a native HTML table: rows of records with the same
fields, such as pages, posts or media files. They are styling only. Sorting,
filtering, selection and paging stay in the app (the CMS drives them with
TanStack Table); the parts show the state they're given.

For a handful of label and value pairs, a list or a [Card](/layout/card/)
reads better than a table.

## Basic table

Compose `Table`, `THead`, `TBody`, `TRow`, `TH` and `TCell`. Give the table
a name with `aria-label`, `aria-labelledby` or `caption`. Use `align='end'`
on both the header and the cells of number and date columns, so digits line
up.

## Sorting

Give a header `sort` (`'ascending'`, `'descending'` or `'none'`) and
`onSort`. It renders a button with the direction's icon and sets `aria-sort`
on the sorted column. The app decides what the next direction is.

## Accessibility

- It's a native `<table>`, so screen readers announce rows, columns and the
  header of each cell. Header cells get `scope="col"` in `THead` and
  `scope="row"` in the body.
- A sortable header holds a real `<button>` (Tab, then Enter or Space) and
  sets `aria-sort="ascending"` or `"descending"` on the sorted column only.
- Name every table with `aria-label`, `aria-labelledby` or a `caption`.
- `selected` sets `aria-selected`, but most screen readers only announce it
  in grids, so always show selection with a labelled checkbox too.
- Name icon-only row actions with the row's item: “Delete Admissions 2027”.

## Props

### Table

| Prop                            | Type                                      | Default     |
| ------------------------------- | ----------------------------------------- | ----------- |
| `density`                       | `'compact' \| 'regular'`                  | `'regular'` |
| `striped`                       | `boolean`                                 | `false`     |
| `stickyHeader`                  | `boolean`                                 | `false`     |
| `caption`                       | `JSX.Element`; a visible caption          |             |
| `aria-label`, `aria-labelledby` | `string`; names the table                 |             |
| `class`                         | `string`; applies to the scroll container |             |

### TH

| Prop                 | Type                                         | Default                        |
| -------------------- | -------------------------------------------- | ------------------------------ |
| `sort`               | `'ascending' \| 'descending' \| 'none'`      |                                |
| `onSort`             | `() => void`                                 |                                |
| `align`              | `'start' \| 'center' \| 'end'`               | `'start'`                      |
| `scope`              | `'col' \| 'row' \| 'colgroup' \| 'rowgroup'` | `'col'` in THead, else `'row'` |
| `colSpan`, `rowSpan` | `number`                                     |                                |

### TRow and TCell

| Part    | Props                                              |
| ------- | -------------------------------------------------- |
| `TRow`  | `selected`, `onClick`, `class`, `children`         |
| `TCell` | `align`, `colSpan`, `rowSpan`, `class`, `children` |

`THead` and `TBody` take `class` and `children`.
