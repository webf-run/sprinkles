```tsx
import { Button } from '@webf/sprinkles';
```

A button starts an action: save, publish, delete. Give it `href` and it
renders a link that looks like a button, for navigation that should read as
a call to action. For a link inside text, use [Link](/navigation/link/).

## Variants

`variant` says what the action means, not what colour it is.

| Variant     | Use it for                                                            |
| ----------- | --------------------------------------------------------------------- |
| `accent`    | The one call to action in a view (default).                           |
| `primary`   | A strong action without the accent colour.                            |
| `secondary` | Everything else. Most buttons are secondary.                          |
| `negative`  | Destructive actions that can't be undone easily.                      |
| `highlight` | A design's second emphasis colour, for marketing pages that have one. |

## Fill style

`fillStyle='bold'` (default) fills the button; `outline` draws only the border
and label, for actions that sit beside a bold one.

## Sizes

One scale for every control: S, M, L and XL are 24, 32, 40 and 48 px tall.
Padding, text and icon size follow. M is the default; use L or XL for
marketing calls to action, and S only in dense tables and toolbars.

</ExampleBlock>

## States

Every state is designed: hover, pressed, keyboard focus, disabled and
pending. The focus ring appears for keyboard focus only, never on click.
Disabled looks the same for every variant. Pending keeps the label's width,
shows a spinner, and ignores presses.

## Icons

`icon` goes before the label and `iconEnd` after it. A button with only an
icon must have an `aria-label`.

## Static colour

Over photos or a coloured band, `staticColor='white'` or `'black'` ignores the
theme so the button keeps its contrast.

## As a link

With `href`, the button renders an `<a>`. A disabled button with `href`
renders a disabled `<button>`, because a link can't be disabled.

<ExampleBlock code={linkCode}>

</ExampleBlock>

## Accessibility

- Renders a native `<button type="button">` (or `<a>`), so Enter and Space
  work without extra code. Pass `type='submit'` inside forms.
- Pending sets `aria-busy` and `aria-disabled` but keeps the button
  focusable, so focus isn't lost while an action runs.
- Every size is at least 24 × 24 px (WCAG 2.2 target size).
- Label and fill pass 4.5:1 contrast in the default theme; `pnpm
check:tokens` checks it.

## Props

| Prop          | Type                                                                | Default    |
| ------------- | ------------------------------------------------------------------- | ---------- |
| `variant`     | `'accent' \| 'primary' \| 'secondary' \| 'negative' \| 'highlight'` | `'accent'` |
| `fillStyle`   | `'bold' \| 'outline'`                                               | `'bold'`   |
| `size`        | `'s' \| 'm' \| 'l' \| 'xl'`                                         | `'m'`      |
| `staticColor` | `'white' \| 'black'`                                                |            |
| `pending`     | `boolean`                                                           | `false`    |
| `disabled`    | `boolean`                                                           | `false`    |
| `href`        | `string`; renders an `<a>`                                          |            |
| `icon`        | a lucide-solid icon, before the label                               |            |
| `iconEnd`     | a lucide-solid icon, after the label                                |            |
| `type`        | `'button' \| 'submit' \| 'reset'`                                   | `'button'` |
| `aria-label`  | `string`; required without a visible label                          |            |
