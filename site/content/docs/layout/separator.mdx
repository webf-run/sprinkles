A separator is a thin line between groups of content: rows of settings, the
sections of a card, groups of buttons in a toolbar. Spacing alone often does
the job; reach for a line when groups sit close together. To group content
on its own surface, use a [Card](/layout/card).

## Decorative

When the line only echoes a break that headings or layout already make,
mark it `decorative` so screen readers skip it.

<ExampleBlock code={decorativeCode}>

</ExampleBlock>

## Accessibility

- By default it has `role="separator"` (plus `aria-orientation="vertical"`
  when vertical), so screen readers announce the break between groups.
- `decorative` sets `role="none"`, for lines that add nothing a heading or
  the layout doesn't already say.
- It isn't focusable or interactive.

## Props

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `size`        | `'s' \| 'm' \| 'l'`          | `'s'`          |
| `decorative`  | `boolean`                    | `false`        |
| `class`       | `string`                     |                |
