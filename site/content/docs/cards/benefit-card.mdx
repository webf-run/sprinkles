`BenefitCard` pairs an optional icon with a heading and a short bulleted list. Use it for "why choose us" sections, product benefit grids, service differentiators, or any block that summarizes a handful of reasons with a short list. The content is flexible, so it can be used across education websites, SaaS products, agency portfolios, and other content-focused interfaces.

## Basic

The basic example demonstrates the default `BenefitCard` configuration. It includes an icon, a heading, and a short list of benefits. Use this version when you need a simple benefit or feature explanation without additional visual customization.

## Color variants

The color variants example demonstrates how `BenefitCard` can use different semantic color treatments. These variants are useful when you want to visually distinguish different groups of benefits while keeping the colors consistent with the design system.

Available variants include `default`, `muted`, `accent`, `inverse`, `purple`, `orange`, `green`, `blue`, and `neutral`.

## Sizes

The sizes example demonstrates the three available card sizes: `sm`, `md`, and `lg`. Use different sizes depending on the amount of content available and the visual hierarchy of the section.

- `sm` — Compact cards for dense layouts or smaller benefit lists.
- `md` — The default size for most sections.
- `lg` — Larger cards for prominent benefit or feature sections.

## Hover effects

The hover effects example demonstrates how to add interaction to the card using the `effect` prop.

- `none` — No hover animation.
- `lift` — The card moves slightly upward when hovered.
- `glow` — The card receives a subtle shadow effect on hover.

Use `none` for a static design, or use `lift` or `glow` when you want the cards to provide visual feedback during interaction.

## Props

| Prop      | Type                                                                                                      | Default     | Description                      |
| --------- | --------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------- |
| `title`   | `string`                                                                                                  | —           | Card heading.                    |
| `bullets` | `string[]`                                                                                                | —           | Short list of supporting points. |
| `icon`    | `AstroComponent`                                                                                          | —           | Optional Lucide icon component.  |
| `variant` | `'default' \| 'muted' \| 'accent' \| 'inverse' \| 'purple' \| 'orange' \| 'green' \| 'blue' \| 'neutral'` | `'default'` | Token-based color treatment.     |
| `size`    | `'sm' \| 'md' \| 'lg'`                                                                                    | `'md'`      | Card spacing and type scale.     |
| `effect`  | `'none' \| 'lift' \| 'glow'`                                                                              | `'none'`    | Hover effect.                    |
| `class`   | `string`                                                                                                  | —           | Additional Tailwind utilities.   |
